# AI usage

We used AI assistance throughout, and most of the code was AI-written. This is a specific
account of what it did and what we did.

| Tool | What it wrote or shaped | What we changed afterwards, and why |
| --- | --- | --- |
| Claude (Anthropic, claude.ai) | First drafts of almost all code beyond the starter kit: the indexer stages (`extract`, `clean`, `chunk`, `embed`, `store` with the versioned-collection pointer flip), the api query pipeline (`services/answer.py`, `guards.py`, `cache.py`, `prompt.py`), the Chroma retriever with the embedding-pin check, the Ollama and hosted providers, the four functions in `eval/run_eval.py`, `eval/tune_chunking.py`, `eval/cache_threshold.py`, the Dockerfiles, every Kubernetes manifest, `ci.yml` and `cd.yml`, the tests, and drafts of these docs and ADRs. It also read the FAST-NUCES handbooks on the website to propose golden-set questions with clause numbers. | We ran every command ourselves on minikube (WSL Ubuntu) and filled every measured number from our own runs. |
| Claude, while we debugged | Diagnosed the failures we hit and proposed fixes; we applied, tested and committed each one | **1. Every answer fell back.** The log said `provider_error`. We raised `LLM_TIMEOUT` from 60 to 240 s (CPU generation is slow), but it still failed. Running the real provider call inside the api pod showed the citation came back as "5. Academic Assessment **)** Academic Warning/Probation": the prompt builder replaced `>` with `)`, so no citation matched a retrieved chunk. Fixed in `prompt.py`, with a regression test. **2. The 2025 handbook disappeared from nu.edu.pk (404).** Sourced from the Wayback Machine, recorded in the manifest. **3. Golden sections that did not exist:** `make sections` showed the Student Handbook's inline chapter headings, so we re-pointed q10, q11 and q17. **4. CI failures:** the OCR tests needed poppler on the runner; Trivy flagged setuptools 70.3.0, first as the base image's copy (upgraded), then as pip's vendored SBOM, so we removed pip from the runtime images. **5. Measured settings replaced the drafts' guesses:** chunks 400/50 → 200/30, relevance floor 0.45 → 0.69, cache threshold 0.95 → 0.88, eval client timeout 120 → 600 s. **6.** The pod-deletion and pin-guard evidence commands were corrected after the first versions captured the wrong pod. |
| Claude | Drafted these documents from our measured outputs | We checked every number against `docs/evidence/` and `eval/results.json`, and rewrote Engineering Note 7 from our own experience. |

Both partners can explain every file. The ADRs, the probes, the pin check, the cache
invalidation and the gate are the parts we expect to be asked about in a viva.
